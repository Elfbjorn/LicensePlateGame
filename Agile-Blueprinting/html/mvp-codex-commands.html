MVP Codex Commands and Variables

This artifact defines the command names and variable prompts for the first Codex MVP skills.

Command Naming

Plugins provide the team context. Skill names should be short, descriptive, and clear even when a user has multiple plugins installed.

MVP Commands

Plugin Skill Command Purpose Primary Output
Product plugin prd-generator Guide a user through creating a PRD/blueprint PRD / blueprint artifact
Product plugin prd-readiness-review Review whether a PRD is ready for Engineering/Codex-assisted build PRD readiness review
Engineering plugin implementation-agent Implement approved PRD scope in the target repo Code changes and implementation artifact
Engineering plugin unit-test-agent Add/run unit tests mapped to PRD acceptance criteria Unit test artifact
Engineering plugin e2e-test-agent Add/run E2E tests mapped to critical workflow and acceptance criteria E2E test artifact

Prompting Rules

  • Ask only for variables that are needed for the selected command.
  • Accept "unknown" when the user does not have an answer.
  • Persist unknowns as open questions or assumptions.
  • Do not block PRD generation only because some answers are unavailable.
  • Do block implementation when the PRD is missing, contradictory, or not actionable.
  • Do block tests when repo, implementation, environment, or command context is unavailable.
