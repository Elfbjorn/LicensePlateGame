Agent Prompt Files

This directory is the staging area for individual agent prompt files.

The current consolidated prompt library remains in ../AGENT-PROMPTS.md, but each reusable agent prompt should eventually become its own Markdown file here.

Each file should represent one future Codex skill or skill seed.

Recommended pattern:

agent-prompts/
  prd-generator.md
  prd-readiness-review.md
  implementation-agent.md
  unit-test-agent.md
  e2e-test-agent.md

Each prompt file should include:

  • Purpose
  • When to use it
  • Required inputs
  • Guided questions or workflow steps
  • Expected outputs
  • Stop conditions
  • HITL/frontmatter expectations
  • Future skill/plugin bundle target
